# Dodge the Magma (pygame-ce)

This repository now includes a modular Python implementation of **Dodge the Magma with Shield** using **pygame-ce**.

## Install

```bash
python -m pip install -r requirements.txt
```

## Run

```bash
python -m dodge_magma_ce.main
```

## Controls

- `A` move left
- `D` move right
- `SPACE` jump
- `E` activate shield (with cooldown)
- `R` restart after game over
- `C` quit after game over
